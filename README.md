# mobile2_2320007_20262

Praktikum Modul 10 - Pemrograman Mobile 2

## Teknologi yang Digunakan
- React Native
- Expo SDK 58
- TypeScript
- Expo Router

## Fitur Aplikasi
- Splash Screen
- Login & Register
- Tab Navigation (Home, Produk, Transaksi, Report, Profil)
- Manajemen Produk
- Laporan Penjualan

## Cara Menjalankan
```bash
npm install
npx expo start
```
